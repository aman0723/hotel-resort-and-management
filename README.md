# Palm Horizon Resort & Spa | Hotel & Resort Management System

An executive web-based Hotel and Resort Management System designed for live room inventory monitoring, guest reservations, revenue tracking, and front-desk hotel operations.

## Architecture & System Modules
1. **Admin Operations Dashboard (`admin.html`)**: Real-time room status grid, dynamic KPI analytics (Total inventory, Occupancy %, Active revenue), walk-in booking management with strict input validations, and digital reservation receipts.
2. **Rooms & Suites (`rooms.html`)**: Room category directory, amenity listings, and floor layouts.
3. **Customer Booking Portal (`booking.html`)**: Guest-facing online reservation portal.
4. **Access Control & Authentication (`login.html`)**: Secure staff & administrator login authentication.

## Tech Stack
- Pure Semantic HTML5 & Modern CSS3 (Midnight Glassmorphism & Champagne Gold Theme)
- Interactive JavaScript (In-Memory Data Structures, Real-Time Input Validations, Dynamic Telemetry Calculations)
